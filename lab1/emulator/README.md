# Емулятор IoT-датчиків

Емулятор розроблений для третьої лабораторної роботи з хмарних технологій.

Для емуляції використовую Node.js. Програма імітує роботу трьох датчиків: температури, вологості та освітленості.

## Датчики

У програмі реалізовано три датчики:

- Temperature — вимірювання температури в °C.
- Humidity — вимірювання вологості у %.
- Light — вимірювання освітленості в lux.

Кожен датчик має власний ідентифікатор та інтервал надсилання повідомлень.

## Налаштування

Налаштування зберігаються у файлі `.env`.

Для кожного датчика можна задати окрему частоту надсилання в межах від 20 до 100 мілісекунд.

Також у конфігурації задаються адреса приймача та ключ доступу.

## Передача даних

Дані передаються HTTP POST-запитами у форматі JSON.

Кожне повідомлення містить:
- Ідентифікатор датчика.
- Тип датчика.
- Значення вимірювання та одиницю виміру.
- Географічні координати.
- Час вимірювання у форматі UTC.

## Журнал роботи

Під час роботи програма записує інформацію про надіслані повідомлення та помилки.

Статистика показує загальну кількість успішно надісланих повідомлень і помилок для кожного датчика.

## Запуск

Для запуску потрібен Node.js 22 або новіший.

Спочатку потрібно створити файл налаштувань:

```bash
cp .env.example .env
```

Встановити параметри підключення та запустити емулятор:

```bash
npm start
```

Для зупинки програми використовується `Ctrl+C`.

## Запуск через Docker

Зібрати Docker image:

```bash
docker build -t iot-sensor-emulator .
```

Запустити контейнер:

```bash
docker run --rm --env-file .env iot-sensor-emulator
```

Емулятор запускається на час тестування та демонстрації роботи системи.
